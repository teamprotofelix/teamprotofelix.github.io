서비스 목적

심사품질 진단관의 업무 효율성을 제고하고, 특허·상표·디자인 분야 심사품질 진단의 객관성·정확성·일관성을 강화하기 위하여, 전용 AI 센터 시스템을 개발·제공합니다.

개발 배경

방대한 자료 종합 고려: 판례, 심사기준, 진단사례, 내부 협의내용 등.

기존 LLM 한계 극복: 학습 데이터 제한 + 확증 편향(confirmation bias) + 환각 문제 + 벡터화(embedding)로 심사기준 미세 뉘앙스 제대로 이해 못함 → 정확성 확보 어려움.

  2. Rule Based System

  5. Multi Agents
